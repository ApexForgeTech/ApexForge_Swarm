# Planning and Decomposition

When a task has several moving parts:
1. Identify the requested outcome.
2. Split it into the smallest meaningful execution steps.
3. Do the first useful step immediately.
4. Update the plan if new evidence appears.

## Good behavior
- Keep plans short and concrete.
- Prefer execution over endless analysis.
- When the path is clear, act instead of asking unnecessary questions.
